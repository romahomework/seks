# Расчёт полимерных колодцев на всплытие (СП 399.1325800.2018)

Файл: [`Расчет_колодцев_на_всплытие_СП399.xlsx`](Расчет_колодцев_на_всплытие_СП399.xlsx)

Расчёт выборочно для 3 колодцев по приложению Д СП 399.1325800.2018 «Методика расчёта
на всплытие трубопроводов, колодцев и ёмкостей», раздел «Колодцы».

> **Исходные данные в файле — ПРИМЕР.** Заменить жёлтые ячейки на листе «Расчёт»
> (колонки D–F) данными проекта: номер колодца, наружный диаметр, глубина, расчётный УГВ,
> γ и α грунта обратной засыпки (отчёт ИГИ), масса колодца и опорной плиты (каталог
> производителя). Остальное пересчитается автоматически.

## Методика

Расчёт колодца на всплытие сводится к определению массы якоря:

| Формула | Назначение |
|---|---|
| mя = mя.т · k, k = 1,25 | (Д.8) требуемая масса якоря |
| mя.т = (FA − Fтр − Fк − Fпл) / g | (Д.9) теоретическая масса якоря |
| FA = π · ρ · g · Dн²/4 · H | (Д.10) сила Архимеда |
| Fтр = γ · h²/2 · π · Dн · tg²(45° − α/2) · tg α | (Д.11) сила трения грунта по боковой поверхности |
| Fк = mк · g | (Д.12) вес колодца |
| Fпл = mпл · g | (Д.13) вес опорной плиты |

Обозначения: Dн — наружный диаметр колодца, м; h — глубина колодца, м;
H = h − hw — высота погружённой в воду части колодца, м (hw — глубина расчётного УГВ);
γ — удельный вес грунта, кН/м³; α — угол внутреннего трения грунта, град;
mк, mпл — масса колодца и опорной плиты, кг.

Если mя.т ≤ 0 — удерживающих сил достаточно, якорь не требуется.

## Примечания

1. УГВ принимается максимально возможным (с учётом сезонного подъёма и подтопления).
2. Формула (Д.11) предполагает уплотнённую обратную засыпку; при засыпке без уплотнения
   рекомендуется дополнительно проверить колодец без учёта трения.
3. В тексте СП формула (Д.10) записана как FA = πρ(Dн²/4)H; множитель g добавлен,
   чтобы получить силу в ньютонах.
4. Строка «Vб.взв» (объём бетона якоря с учётом взвешивания ниже УГВ) — справочная,
   сверх требований СП.
5. Формулы взяты из открытых копий текста СП. Перед выпуском сверить с действующей
   редакцией СП 399.1325800.2018 (с изменениями).
